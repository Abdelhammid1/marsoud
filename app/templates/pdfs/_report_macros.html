{# MARSOUD-TKT-PDFS-02-FIN-REPORTS (2026-08-29) — reusable macros for financial-statement PDF templates. Every financial report (balance sheet, income statement, cash flow, VAT, expenses summary, profitability, aging reports…) shares the same shape: a title + a list of account rows + a subtotal. `account_group` captures that pattern so each report template just calls the macro N times per section instead of open-coding a 20-line table per group. Kept out of pdfs/_shell.html because the shell is for PAGE chrome (corner accents, brand row, footer). Report-specific primitives belong here so future tickets adding more macros (a `subtotal_row` for indented sub-totals, a `three_column_totals` for tax-report summaries) can grow without bloating the shell.
