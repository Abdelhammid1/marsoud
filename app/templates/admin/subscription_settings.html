⚙️ إعدادات الاشتراك

التحكم في دورة حياة الاشتراك على مستوى المنصة. الإعدادات دي بتأثر على كل الشركات. النظام بيشتغل بالقيم الافتراضية من أول لحظة لو ماغيّرتش حاجة هنا.

{# ─── Reminder thresholds ───────────────────────────────────── #}

قائمة أرقام (افتراضي: {{ default_thresholds|join(', ') }}). مثلاً 7 يعني تذكير قبل الانتهاء بأسبوع. 0 يعني التذكير يوم الانتهاء نفسه.

{# ─── Grace days ────────────────────────────────────────────── #}

خلال الفترة دي بعد انتهاء الاشتراك، النظام يشتغل عادي بس مع banner تحذيري. بعدها يدخل وضع القراءة فقط (لو مفعّل). افتراضي: {{ default_grace }} يوم.

{# MARSOUD-TRIAL-DAYS-SETTING (Abdelhamid 2026-07-22) — trial length is now admin-tunable instead of a hardcoded constant. #}

كل شركة جديدة بتدخل النظام تاخد الفترة دي مجاناً بجميع المميزات. بعدها بتتحكم فيها قيود الباقة المختارة. افتراضي: {{ default_trial_days }} يوم.

{# MARSOUD-API-RATE-LIMIT (Abdelhamid 2026-07-22) — cap on per-ApiToken requests per minute. Applies to /api/v1/*. #}

كل توكن API بيقدر يبعت هذا العدد من الطلبات على /api/v1/* في الدقيقة الواحدة. لو تجاوز، النظام بيرجّع HTTP 429. افتراضي: {{ default_api_rate_limit }} طلب/دقيقة.

📖 ملاحظات

  • تنبيهات الإيميل بتتبعت لمالك الشركة على المواعيد المحدّدة. مفيش تكرار — كل تنبيه بيتبعت مرة واحدة لكل دورة اشتراك.
  • الـ super-admin + auth (login/logout) + cron + تجديد الاشتراك دايماً مستثنيين من تقييد القراءة فقط.
  • لما تجدد اشتراك أي شركة من إدارة الاشتراكات، تاريخ التذكيرات بيتمسح عشان الدورة الجديدة تشتغل.
