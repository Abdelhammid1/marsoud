{# MARSOUD-UI-DESIGN-SYSTEM (2026-08-18) — TKT-06/07/08/09. Central design-token layer. Included by both `base.html` (tenant shell) and `admin/base.html` (super-admin shell). Every colour, radius, shadow, spacing, and typography scale reads from here so a designer can tune the whole app by editing one file. Prefix `--ms-` = Marsoud. Existing `.card`, `.btn-primary`, `.badge-*`, `.data-table`, `.input` etc. classes in base.html / admin/base.html are additive on top of this file — those remain the working classes, but now consume the variables so palette drift is impossible. Palette policy: - Brand green is `--ms-brand`. All shades derive from it so the dashboard (was #159b54), tenant btn-primary gradient (was #047857 → #059669) and gradient-heading (was #065F46) stop disagreeing. - Ink is a 4-step neutral (900/700/500/300) — matches the Cairo weight-with-slate-ink pattern already used across the app. - Surfaces use paper white (`--ms-surface`) on a soft grey bg (`--ms-bg`). #}
